# Claude-workflow

Vaste architectuur voor hoe ik Claude gebruik over al mijn projecten heen (claude.ai en Claude Code).

| Pad | Inhoud |
|-----|--------|
| `CLAUDE.md` | Werkafspraken die Claude automatisch leest |
| `frictielog.md` | Wrijvingsmomenten, input voor de maandreview |
| `templates/project-template.md` | Checklist voor een nieuw project |
| `templates/maandreview.md` | Maandelijkse review: top 3 wrijving + één nieuwe feature |
| `skills/` | Eigen skills |

## Ritme
1. **Doorlopend:** wrijving noteren in `frictielog.md`.
2. **Maandelijks:** maandreview invullen, top 3 omzetten, één nieuwe feature testen en meten.
