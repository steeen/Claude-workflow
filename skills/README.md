# Skills

Eén map per skill, elk met een `SKILL.md`:

```
skills/
  <skill-naam>/
    SKILL.md
```

Formaat van `SKILL.md`:

```markdown
---
name: skill-naam
description: Wanneer Claude deze skill moet gebruiken (één zin).
---

# Instructies
...
```

Inspiratie: [anthropics/skills](https://github.com/anthropics/skills).
Opslaan in claude.ai: vraag Claude om de skill voor te stellen, dan verschijnt een opslagkaart.
